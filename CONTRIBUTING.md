# Contributing to Backup Puller Worker

Thank you for your interest in contributing!

## Development Setup

1. Clone repository:
   ```bash
   git clone https://github.com/putuwahyu29/backup-puller-worker.git
   cd backup-puller-worker
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run automated tests:
   ```bash
   npm test
   ```

## Pull Request Guidelines

1. Fork the repository and create your feature branch from `main`.
2. Ensure all existing tests pass and add new unit tests for any bug fixes or new features.
3. Submit a Pull Request with a clear description of your changes.
