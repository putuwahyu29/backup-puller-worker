# Security Policy

## Supported Versions

Only the latest release version receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within `backup-puller-worker`, please report it privately:

1. **Do not create a public GitHub issue.**
2. Send an email to `putu.wahyu.dev@gmail.com` with:
   - Detailed description of the vulnerability
   - Steps to reproduce
   - Potential impact
3. We will respond within 48 hours to confirm receipt and work on a coordinated fix.
